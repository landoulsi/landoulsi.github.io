TerminalPro Free

TerminalPro is a terminal emulator for developers who live in the command line. It runs your own shell and tools, and keeps the things you do all day, such as switching between projects, running several sessions and checking git state, in one window.

Terminal features

  • Tabs and split panes. Split any pane vertically or horizontally, with resizable panes, and rename tabs by double-clicking.
  • Session restore. Your tabs and layout come back when you reopen the app.
  • Your own shell. Runs your login shell and your installed command-line tools.
  • Global hotkey. Show or hide the app from anywhere.
  • Rerun last command. One shortcut reruns the command you just ran.
  • Background commands. Run long commands in the background and get a notification when they finish.
  • AI commands. Ask for AI help without leaving the terminal.

Git support

Every pane knows which repository it is in, so the git state is always in view and you don't have to type git status to find out.

  • Branch in every pane. The current branch shows in the pane's status bar. Switch to another branch from a list.
  • Change counts. See how many lines were added and removed at a glance, and open the list of changed files.
  • Pull indicator. The pane shows when your branch is behind the remote, so you can pull with one click.
  • Pull request link. If the current branch has a GitHub pull request, its number shows in the status bar and opens in your browser.
  • Commit dialog. Review changed files and unpushed commits, then commit and push without leaving the terminal.
  • Open in other tools. Open the current repository in GitHub Desktop, IntelliJ IDEA or VS Code, or reveal the folder in your file manager.

Pull request information uses the GitHub CLI (gh) if it is installed and signed in.
